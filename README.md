# chrome-extension
Chatgpt Chrome Extension for Roman Urdu To English
# Chrome Extension Name
ChatGPT-Extension
T

## Features

- Feature 1: It takes Roman Urdu Text from  Chatgpt text area and translate it into English.
- Feature 2: It will allow user to enter text using speech to text.
- Feature 3: It will allow user to speech in Urdu then using that audio it will convert and make prompt in english.

## Installation

1. Clone the repository to your local machine using `git clone https://github.com/username/repo.git`
2. Navigate to `chrome://extensions` in your Chrome browser.
3. Enable "Developer Mode" in the top right corner.
4. Click on "Load Unpacked" and select the directory of the cloned repository.



##Run
You have to run server for node server.js to trasnlate the roman urdu to english (it will run on localhost:3001

## Usage
When you press any key inside the chatgpt textarea it will show the tooltip ( A button next to the text area ). Upon clicking on it . it will show three button for the features.
